# Song Guesser

Guess the song from a short audio clip. Pick a genre, choose your difficulty, and test how well you know the charts!

**[Live Demo](https://song-guesser-liard.vercel.app/)**

## Features

- Guess songs from Deezer chart previews
- Adjustable difficulty (Easy/Medium/Hard)
- Configurable round count (5-25 rounds)
- Custom built audio player
- Responsive design

## Tech Stack

* [![React][React.js]][React-url]
* **Frontend:** React, Vite, Tailwind CSS
* **Backend:** Node.js, Express
* **Data:** Deezer public API
* **Deployment:** Vercel (frontend), Render (backend), Cloudflare Workers (proxy)
